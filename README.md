# Banco de Dados - Laboratórios

Repositório com os laboratórios desenvolvidos durante a disciplina de **Banco de Dados** na **UNIFEI** (Universidade Federal de Itajubá).

## Autoria
Desenvolvido por **Maria Fernanda Guimarães Soares**.

## Conteúdo
Os laboratórios abrangem conceitos e práticas relacionados a:
- Modelagem de dados  
- SQL (Structured Query Language)  
- Cypher  
- Neo4j  

## Estrutura
As pastas estão organizadas por laboratório (`lab07`, `lab08`, ..., `lab14`), contendo exercícios e práticas de diferentes tópicos da disciplina.

## Tecnologias Utilizadas
- MySQL / PostgreSQL (consultas em SQL)  
- Neo4j (consultas em Cypher)  
- Ferramentas de modelagem de banco de dados  

---

Este repositório tem como objetivo registrar e consolidar os aprendizados da disciplina, servindo como material de estudo e consulta futura.
